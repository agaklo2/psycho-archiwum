Jak zdobyć bezpłatny Client ID (w 3 minuty)?

  1. Wejdź na Google Cloud Console i utwórz bezpłatny projekt (np. Moje PsychoArchiwum).
  2. W menu APIs & Services kliknij Library, wyszukaj Google Drive API i kliknij Enable.
  3. Przejdź do OAuth consent screen, wybierz External, wpisz nazwę aplikacji i swój e-mail.
  4. W zakładce Credentials kliknij + CREATE CREDENTIALS > OAuth client ID.
  5. Wybierz typ Web application. W polu Authorized JavaScript origins dodaj adres, pod którym uruchamiasz plik (np. http://localhost lub http://127.0.0.1:5500).
  6. Skopiuj wygenerowany Client ID i wklej go w pole powyżej.
